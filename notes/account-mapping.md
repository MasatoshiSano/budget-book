# カード → 引き落とし口座の対応関係

最終更新: 2026-08-03

ダッシュボードの「支払い元」は6つに分かれているが、実際に引き落とされる先の銀行口座で見ると
2つに集約される。この対応関係は `site/template.html` の `ACCOUNT_MAP` 定数として実装済みで、
Overviewページの「引き落とし口座別」パネルに表示されている。

## 対応表

| 支払い元（カード/引落） | 実際の引き落とし口座 | 根拠 |
|---|---|---|
| 三井住友カード | 住信SBIネット銀行 | `scripts/parse_bank.py` で「口座振替 ミツイスミトモカード」を重複除外している＝住信SBI明細に載っている |
| イオンカード | 住信SBIネット銀行 | イオンカード明細書に記載の指定口座「スミシンエスビーアイネ支店レモン、口座番号フ-5092\*\*\*」が住信SBIそのもの |
| 銀行引落（家賃・ATM等） | 住信SBIネット銀行（自身） | `data/bank_transactions.json` の元データ |
| PayPayカード | ゆうちょ銀行 | ゆうちょ明細CSVに「自払 PAYPAYカード 63,811円」（2026/6/29）があり、PayPayカード6月分の請求額と完全一致 |
| 楽天カード | ゆうちょ銀行 | 同CSVに「自払 ラクテンカードサービス 75,147円」（2026/6/29）があり、楽天カード6月分の請求額と完全一致 |
| ゆうちょ引落（全労済保険等） | ゆうちょ銀行（自身） | `data/yucho_transactions.json` の元データ |

## まだ内訳を持っていないもの

- **アメックス**：ゆうちょ明細に「自払 アメックス」の行がある（2026/6/10に10,601円、2026/7/10に1円）。
  実際のアメックス利用明細（PDF/CSV）はまだアップロードされていないため、`data/`には存在しない。
  ユーザーからは「アメックスは後回しでいい」との指示あり（2026-08-03時点）。

## この整理から出てきた重要な気づき

「生活費口座（住信SBI）への振込額」の推奨額を検討する際、以前は三井住友カードの支出だけを
ベースラインにしていたが、**イオンカードも同じ住信SBI口座から引き落とされる**ことが分かったため、
2026-08-03にイオンカード分（旅行除く・月平均約4万円弱）を合算して推奨額を
160,000円→210,000円（佐野様130,000円・奥様80,000円）に上方修正した。
同様に、ゆうちょ側（PayPay・楽天・保険・アメックス）についても、必要であれば同じ考え方で
資金繰りの目安を出せる（まだ未着手）。
